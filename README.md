# خياطة وأقمشة العمر — إدارة طلبات الخياطة

## 📲 تثبيت التطبيق على الجوال بضغطة واحدة (APK)

👉 **[اضغط هنا لتحميل وتثبيت التطبيق مباشرة (tailor-orders.apk)](https://github.com/omaramen354-dev/tailor-orders/raw/master/tailor-orders.apk)**

---

تطبيق محلي (بدون سيرفر) لإدارة طلبات الخياطة والقياسات، يعمل على جهاز واحد ويخزّن كل البيانات في `localStorage` داخل المتصفح/الهاتف.

## المزايا

- إضافة وتعديل طلبات الخياطة مع القياسات والتواريخ والأسعار.
- حالات الطلب (جديد / قيد التنفيذ / جاهز / مستلم) وأرشيف قابل للبحث.
- لوحة إحصائيات: طلبات اليوم، التسليمات، المبالغ المتبقية.
- تنبيهات داخل التطبيق (تسليم قريب، متأخر، عربون) مع إمكانية إشعارات النظام.
- نسخ احتياطي واستعادة (تصدير/استيراد ملف).
- واجهة عربية RTL، مهيّأة للهاتف، ويعمل كـ PWA بعد البناء.

## التقنيات

React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · Vitest · Capacitor (اختياري لبناء APK)

## التشغيل

```bash
npm install
npm run dev        # بيئة التطوير
npm run build      # ينتج dist/index.html كملف واحد
npm run preview    # معاينة نسخة البناء
```

## الفحوصات

```bash
npm run typecheck  # TypeScript
npm test           # 28 اختباراً لمنطق الطلبات والتنبيهات (Vitest)
```

## بنية المشروع

```
src/
  App.tsx                 واجهة التطبيق الكاملة
  lib/orders.ts           الأنواع + منطق الطلبات النقي
  lib/notifications.ts    منطق التنبيهات النقي
  lib/*.test.ts           اختبارات Vitest
public/
  sw.js                   Service Worker (تنقل network-first)
  manifest.json           بيانات PWA
docs/APK.md               دليل بناء APK محلي خطوة بخطوة
```

## بناء APK

راجع [`docs/APK.md`](docs/APK.md) — يشرح بيئة Java/Android SDK، أوامر Capacitor، إخراج `app-debug.apk`، والتوقيع للتحديثات، مع ملاحظة مهمة عن إشعارات النظام داخل WebView.

## ملاحظات

- لا يوجد تسجيل دخول أو مزامنة سحابية: البيانات محلية بالكامل، فخُذ نسخة احتياطية دورياً.
